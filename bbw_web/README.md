# bbw_web — 全功能 Web 客户端

目标：**APK 有的业务能力，Web 都要能走协议完成**；UI 简洁，**PC 侧栏 + 手机底栏**自适应。

```
浏览器 SPA（简洁浅色 UI）
        │ Cookie bbw_sid
        ▼
bff_server.py  语义 API（覆盖主功能域）
        │ 每用户 BeibeiwuApp + 心跳
        ▼
bbw_protocol → banghua 后端（与 APK 同协议）
```

## 启动

```powershell
cd <repo-root>
python -m bbw_web --port 8765
# http://127.0.0.1:8765/
```

## 功能导航

| 模块 | 能力 |
|---|---|
| **首页** | 推荐、礼物、在线状态、快捷入口 |
| **广场** | 推荐/幻灯、话题搜索与创建 |
| **匹配** | 次数/卡、在线·同城、漂流瓶、约会、买卡 |
| **社交** | 关注/取关/粉丝/好友申请/黑名单/查资料/举报 |
| **房间** | 榜单、建房、权限、KTV 搜索、RTC token |
| **消息** | TIM UserSig、融云 token、尝试 CDN 收发 |
| **钱包** | 币/VIP、试用、兑 VIP、充币/VIP 下单、提现、礼物背包 |
| **任务** | 热门任务列表与领取 |
| **我的** | 资料、改昵称、实名说明、礼仪分、推荐码、退出 |
| **协议台** | 任意 `do=` / redis 调用、action 列表 |

登录：密码 · 一键 · 短信。多浏览器 = 多账号。

## 与 APK 的边界

| 类型 | Web |
|---|---|
| HTTP 业务（登录匹配社交任务房间下单…） | ✅ 同协议 |
| IM 完整体验 | ⚠️ 凭证 + 可选 TIM CDN；正式应用建议官方 SDK |
| 刷脸实名 | ⚠️ 建议官方 App；Web 可编排 Init/Describe |
| 微信/支付宝到账 | ⚠️ 可下单；收银依赖官方商户/包名 |
